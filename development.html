Integration Guide

Integrate Equorum Revenue Bonds into your protocol in three simple steps:

1. Create a Revenue Bond Series

Call the createSeries function on the RevenueBondFactory contract:

function createSeries( string memory name, string memory symbol, uint256 revenueShareBPS, // e.g., 2000 = 20% uint256 duration, // in seconds uint256 totalSupply ) external returns (address series, address router);

2. Distribute Revenue

Send revenue to the Router contract using the distributeRevenue function:

function distributeRevenue() external payable;

3. Bond Holders Claim

Bond holders can claim their share of distributed revenue anytime:

function claimRevenue() external;

Key Features

ERC-20 Compatible: Revenue Bonds are standard ERC-20 tokens, tradeable on any DEX or CEX.
Automatic Distribution: Revenue is distributed proportionally to all bond holders based on their holdings.
Hybrid Series Support: Optional principal protection through escrow for guaranteed capital return.
On-Chain Reputation: Protocol payment history tracked via ProtocolReputationRegistry.
Permissionless: Any protocol can create a Revenue Bond series without approval.
